用法与快捷键

画图

左侧工具栏选工具后在画布上拖拽；Shift 画正方形/正圆、直线吸附 15°。

架构图 / 流程图（重点）

形状库：左侧工具栏已内置 16 种节点——矩形/圆角/开始结束（体育场）/判断（菱形）/输入输出（平行四边形）/准备（六边形）/椭圆/三角/星形/数据库（圆柱）/云/文档/便签/角色/模块/容器。

连线（⇢ 工具）：点第一个图形再点第二个图形即可连线；连的是"真连线"——拖动图形时连线自动跟随并重新绕线。双击连线可加标签（是/否、异步）。选中连线后拖两端的小圆点可以改接到别的图形上。

自动避障：连线的路径会自动绕开中间挡路的元素（A* 正交路由）；两条线交叉的地方会画一个小拱（跳线），读图不会看串。顶部「整理 ▾」里可以分别关掉这两个效果。

也可以选中两个图形按 Ctrl+L 直接连线。

容器（frame）：用它框住一组元素表示模块/层/边界；拖动容器会带着里面的元素一起走；双击容器改标题。

模板：顶部「模板 ▾」一键插入——流程图（基础/登录/订单）、架构图（经典四层、微服务+异步）、时序图（下单支付、登录鉴权）、泳道图（跨部门流程、故障处理）、数据流管道、思维导图。

时序图会自动画激活条（谁在执行：收到请求到发出回复之间的细窄条，同步调用会逐层嵌套缩进，自消息有独立小条）；参与者拖动时生命线、消息、激活条一起跟随。选中激活条可拖上下角改长度；在参与者上右键 →「在此加激活条」可手动补一条。

整理：顶部「整理 ▾」按连线关系自动分层排版（从上到下 / 从左到右），无连线时退化为网格对齐；也可以把选中元素装进容器、或关闭连线避让与交叉跳线。

🎙 多人讨论模式

说话人区分：每段录音会算出音量/过零率/基频/频谱重心，把音色接近的归为同一个人（最多 4 人），转写里显示「说话人 1／2…」。点一下某段就能给这个人改名（如"张三"），后面的转写和 AI 整理的方案都会用这个名字。

多端各自录音（最准）：先开顶部 🔗 同步，每个人用自己那台设备开「🎙 讨论」并点「本机名称」写上自己是谁——几台设备录各自的麦克风，转写会自动合并成一份，标出「谁说的」。这比声学猜测准得多。

实时关键词标记：说话里出现"决定/风险/待办/问题/依赖"就会在转写里打上彩色标签，面板上方实时统计「决定 2 · 风险 1 · 待办 3」，帮你在讨论中盯住关键内容。

待办清单：「结束并整理」时 AI 会额外把待办抽成结构化清单（谁 / 做什么 / 什么时候），方案弹窗里点「待办写成画板」——每条生成一张便签 + 负责人，直接当任务板用。在画布上点便签左上角的方框就能勾选（完成会划掉）。

待办总表：顶部「整理 ▾ → 待办总表」把所有画板的待办汇总在一张表里（按画板分组、显示未完成/已完成），可以直接在表里勾选（改的是画布上的便签）、按"只看未完成"筛选、一键复制未完成项、导出 Markdown。

建议节点：讨论里说"还需要一个风控服务""再加个消息队列"这类话时，点面板「建议节点」会列出提到但图上还没有的节点，点一下就补到画布右侧（不会重复提同一个）。

声纹校验：面板会自动提示两种可能出错的情况——一台设备上出现了多种音色（说明这个麦克风前不止一个人），或两台设备的音色过于接近（可能是同一个人在用两台设备）。

一键周报：「整理 ▾ → 一键生成周报」会把所有画板的结构 + 备注 + 待办（含完成状态）打包给 AI，生成一份「本周进展 / 关键结论 / 待办与分工 / 风险与阻塞 / 下周计划」的周报，可直接复制或写入新画板。待办也会自动同步到本机服务（`GET /api/todos`），方便脚本或别的系统读取。

🔍 网页审阅（做网页设计时用）

顶部「审阅」：填网址（含 http://localhost:3000 这类本地开发地址）、本地文件路径（如 D:\proj\index.html），或直接贴 HTML 源码，然后「抓取并检查」——服务端会抓下来做结构分析：标题层级树、地标（header/nav/main/footer）、元素计数、配色清单，以及一批静态检查（缺 lang / 缺 viewport / 图片没 alt / 标题层级跳跃 / 空链接空按钮 / 表单没标签 / 重复 id / 缺 main / 内联样式过多…）。

拿到结构后可以：「AI 设计评审」让 AI 按"总体印象 / 信息层级 / 视觉配色 / 交互可用性 / 无障碍规范 / 优先级建议"给一份可落地的评审，「画成页面结构图」把标题层级画到白板上直接讨论改法，「问题变成待办」把每条检查转成待办便签（自动进待办总表），「尝试内嵌预览」用 iframe 打开（很多站点会拒绝被内嵌，本地/同源页面通常可以）。

留存对比：每次审阅都会存一条记录（按地址存最近 12 次）。再抓同一个地址时，面板会显示「✅ 已修复 N · 🆕 新增 M · ⚠️ 仍在 K」并列出修好/新增的具体条目——改完代码再点一次「抓取并检查」就能看到有没有修掉。点「审阅历史」看这个地址的历史与逐次变化。

对着结构图改代码：结构图上的节点带着对应的 CSS 选择器（有 id 给 #id、有 class 给 h2.cls、都没有给 h3:nth-of-type(2)）。双击节点即复制选择器到剪贴板；右键也有。改完回到审阅面板再抓一次即可验证。

修复清单：每条检查都带「怎么修」（点检查项下方那行灰字看），点「复制修复清单」得到一份带复选框的 Markdown，可以直接当任务清单往下做。

批量审阅：点「批量审阅…」，每行写一个地址（本地开发地址也行），逐个审完给出一张总表：各页问题数 + 多页共有的问题（按页数排序，优先统一修）。共有问题可以一键写成待办。

团队规范：点「规范…」可以配一套规则存在服务端 web_rules.json——规范色板（超出即报错）、最多颜色数、内联样式上限、禁用标签（marquee/center/font…）、必须有 viewport/main/description、页面必须包含的文字（如版权符号）。每次审阅自动按规范检查。色板不用手敲：点「从 tokens.json 导入色板」选一份设计 tokens，会自动把里面所有颜色（含 rgba、#abc 简写、深层嵌套）抽出来填进去。

接 CI：命令行也能跑同一套检查——python web审查.py http://localhost:3000，不合规就退出码 1，可以直接挂到构建/预提交里。--json 输出机器可读结果，--fail-on warn|none 控制严格程度。

截图 + 结构一起审：「AI 设计评审」默认会勾上「带白板截图」——先把白板上的截图交给视觉模型转述，再连同结构分析一起给 AI，这样既有"结构上哪里不对"也有"看起来哪里别扭"。

设计稿不方便给 URL 时，也可以直接把网页截图 Ctrl+V 贴到白板上，让 AI 照着看——审阅面板和截图讨论是互补的。审阅历史还会进周报素材（本周审阅了几个页面、修掉多少问题）。

圈风险：讨论里标记到"风险/问题"后，点面板「圈风险」会按文字相似度找到对应节点，自动套一个红虚线圈并写上"谁提的 + 原话"。匹配用的是"覆盖率"口径（一句话里出现节点名即可），1~2 个字的短标签会自动降权。

讨论回放联动：本机录的每段音频会留着（只在内存里），转写里点「▶ 听这段」可回听；时间线面板开「🎧 语音联动」后，拖回放滑块会同步播放当时那一段，等于把"图怎么变的"和"当时怎么说的"对上。

顶部「🎙 讨论」开启后，AI 进入**持续录音转写**状态：麦克风一直开着，说话停顿约 1.8 秒就自动切成一段送去转写（也有 20 秒上限），左下角面板实时显示转写内容与已录音时长。「⏸」可暂停，「结束并整理」会把语音转写 + 图形每一步变化一起交给 AI，整理成一份会议纪要式方案（背景 / 关键结论 / 方案要点 / 争议与未决 / 待办与分工 / 图上的关键变化），可以直接复制，或「写入新画板」变成一页纪要。

图形变化时间线：从打开页面起，画布每改一步都会记一条（新增/删除/改文字/移动/改样式，5 秒内相同变化会合并）。面板「🕘」里可以看完整过程、导出文本，或点「▶ 回放」拖着滑块看图形是怎么一步步长出来的（回放时不能编辑，退出即可恢复）。时间线摘要会持久化，回放快照保留最近 60 步。

🖊 画成图：让 AI 把讨论结论直接画成一张流程图（新画板）——问题/目标起头、结论与动作居中、需要拍板的地方用菱形，待办用便签；方案弹窗里也有这个按钮。

⬇ Markdown：导出完整讨论记录 `.md`——方案 + 带说话人的转写 + 图形变化时间线 + 每个画板的截图与 Mermaid 源码，可以直接进 wiki / 仓库。

多画板（多页）

顶部那条画板条可以开多张画板（每页的元素和视口各自独立）：点标签切换、双击重命名、「目录」「＋ 新画板」「复制」「删除」。点「目录」打开卡片式缩略图导航（可排序 / 复制 / 删除 / 引用 / 从这页开始演示）。导出时「PNG ▾ → 全部画板」可以导出多页 PDF、每页一张 PNG 或拼图 SVG；「整理 ▾ → 从其它画板复制内容」可以把别页的图整份搬过来继续改。

画板引用块：在「整理 ▾ → 在这里插入画板引用块」放一个"活块"，框里实时显示另一个画板的内容——源画板一改它就跟着变。双击引用块会下钻：直接跳到源画板并选中你点的那个元素（右键也有「跳到源画板 / 下钻」）。跨画板讲方案时很好用（总览页挂着各分册）。

▶ 演示：画板条上点「▶ 演示」全屏放映，← →（或空格）翻页、Esc 退出，底部有页码和进度点，内容自动缩放到满屏。

演示时右上角有✏️ 画笔（P）、🔴 激光笔（L）、🧹 清除（C）：画笔在页面上圈重点（翻页自动清除），激光笔让鼠标变成会淡出的红点。画笔/激光只重绘上层，所以跟手不卡。

跨画板对比：「整理 ▾ → 与其它画板对比」会按节点文字 + 关系比对两页，列出只在一侧有的节点/关系、同名但形状不一致的地方——用来检查两份架构图描述是否一致。

体检：顶部「体检」检查这张图有没有毛病——连线穿过了元素、元素叠在一起、判断分支没写是/否、孤立节点、缺开始/结束、交叉太多（点问题可直接定位到出错的元素）。面板顶部有「🔧 一键自动修复」：自动补「是/否」分支标签、补「开始/结束」节点并连好线、有穿框或重叠则自动重排。

导出代码：顶部「代码 ▾」把画布导出成 Mermaid（流程图/时序图/带 subgraph 的架构图）或 PlantUML，可直接粘进 Markdown、README、PR；同一菜单里还能粘贴 Mermaid / PlantUML 导入（自动识别格式，subgraph / package → 容器框）和自动补标题与图例。

导出图片：顶部「PNG ▾」可选带标题栏（标题取画布上最大的标题文字，右上角自动带日期）、再加水印、或纯净版；PDF 与 SVG 同样带标题栏。

选择与编辑

点击选中，Shift 加选，空白处拖拽框选；选中后拖动移动、拖四角缩放；双击图形或文字就地编辑。

Ctrl+A 全选 · Ctrl+C/X/V 复制/剪切/粘贴 · Ctrl+D 再制 · Delete 删除 · 方向键 微移（Shift 加速）

Ctrl+G 编组 · Ctrl+Shift+G 取消编组 · 点中组内任一元素即整组选中（组内相对位置一起移动）

Ctrl+Shift+] 置顶 · Ctrl+Shift+[ 置底 · 右键可打开菜单

视图

滚轮平移 · Ctrl+滚轮 缩放 · 双指捏合缩放 · 空格+拖拽 平移 · Shift+1 适应内容 · Shift+2 缩放到选中

顶部 🧲 开关拖动磁吸：吸附到其它元素的左/中/右、上/中/下（出现红色对齐线）；没命中元素时吸附 20px 网格（网格吸附不画红线）。缩放元素时也会吸附。吸附阈值固定为屏幕 7px，缩放画布后手感不变。

文件

顶部「新建 / 打开 / PNG / SVG / JSON / PDF」；图片可直接 Ctrl+V 粘贴或拖入画布。

AI 助手

右侧输入框对话；可让它画、改、删、连线、对齐、圈注。侧栏「主动提议」让它在发现缺口时主动提醒；「看图」控制是否把截图发给它（默认自动）。

界面语言（🌐 EN / 🌐 中）

顶栏 🌐 EN 一键把界面切成英文，再点一下切回中文 —— 选择会记住。默认中文，不跟随浏览器语言。 覆盖按钮、菜单、面板与常用提示；少数长说明与错误信息仍是中文。

语音（🎤 说话 / 🔊 朗读）

点 🎤 直接说话，说完自动停止并发送；识别走服务端 (`mimo-v2.5-asr`)，不依赖 Google，国内网络可用。

点「朗读:开」后 AI 的回复会用 `mimo-v2.5-tts` 合成语音念出来。

前提：浏览器只在 https 或 127.0.0.1 / localhost 下允许麦克风——用局域网 IP（如 http://192.168.x.x:9091）打开时麦克风会被浏览器禁用，请在本机用 127.0.0.1 访问，或给服务器配 HTTPS。
